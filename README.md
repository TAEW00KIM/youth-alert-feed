# youth-alert-feed

비공식 개인 앱 "또놓쳤지"(iOS)가 읽는 공개 공고 데이터입니다. 정부나 기관의 공식 서비스가 아닙니다. 신청 자격과 마감은 반드시 각 공고의 원문에서 확인하세요.

- 파일: `feed.json` (형식 schemaVersion 1). 하루 4번(06, 11, 16, 21시 KST) 자동으로 갱신합니다.
- 원천과 출처
  - 서울시 청년안심주택 모집공고 게시판 (soco.seoul.go.kr, 서울특별시)
  - 행정안전부 대한민국 공공서비스 정보(보조금24) API (공공데이터포털 data.go.kr)
  - 국토교통부 마이홈포털 공공주택 모집공고 API (공공데이터포털 data.go.kr)
- 각 항목의 `url`은 그 공고의 원문 페이지입니다. 민간임대 사업자 이름 같은 개인 정보는 싣지 않습니다.
